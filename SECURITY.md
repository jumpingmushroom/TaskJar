# Security

TaskJar has **no accounts or authentication** by design (for now): anyone who can reach it can read and change the jar. Run it on a trusted home network only, and don't expose it directly to the internet. If you need remote access, put it behind a VPN or an authenticating reverse proxy.

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://github.com/jumpingmushroom/TaskJar/security/advisories/new) rather than in a public issue. I'll reply as soon as I can.

Only the latest release is supported.
